# 方塊戰場 Block Arena

多人連線 3D 第一人稱槍戰遊戲，瀏覽器直接玩，電腦和手機都支援。

## 玩法
- 一進場就是大亂鬥（每個人互打），最多 16 人
- 身體一槍 25 傷害、爆頭 70 傷害，血量 100
- 被擊倒 3 秒後重生，重生後 1.5 秒內有保護（開槍就會取消）
- 彈匣 30 發，換彈 1.8 秒

**電腦**：WASD 移動、空白鍵跳、滑鼠瞄準、左鍵開槍、R 換彈、按住 Tab 看計分板、Esc 暫停
**手機**（橫放）：左半邊拖曳移動、右半邊拖曳瞄準、按住 🔫 開槍（按住時也能拖曳瞄準）

## 標題畫面
- 科幻霓虹風格，鏡頭在夜晚的場地上空繞行
- **自訂角色**：名字和 16 種顏色，有 3D 預覽（可以拖曳旋轉）
- **設定**：滑鼠／觸控靈敏度、視野、音效和音樂音量、畫質（流暢／高畫質）
- 顯示目前線上人數，有按鈕音效和背景音樂（右上角 ♫ 可以關）

## 房間與對戰
- **大廳**：列出所有房間，點一下就能加入；也可以輸入 4 碼房號加入。房間可以設密碼
- **等待室**：藍隊 vs 紅隊，每隊最多 5 人，可以自己換隊
- **房主**可以設定規則、踢人、開始對戰；房主離開會自動交給下一個人
- **團隊死鬥**：死了 3 秒重生，先達到目標擊殺（25／50／75／100）或時間到（5／10／15 分）擊殺多的隊伍贏
- **回合殲滅**：死了要等下一回合，從隊友視角觀戰；全滅對方贏一回合，先贏 3／5／7 回合的隊伍獲勝
- 沒有友軍傷害，對戰中途可以加入（自動補進人少的隊伍）
- 對戰結束顯示結算畫面（勝利隊伍、比分、MVP、每個人的戰績），12 秒後回到等待室

## 開場
按下開始後，先等所有玩家載入地圖（最多 10 秒，畫面會顯示「等待玩家載入中」），接著倒數 5 秒才開打；倒數時可以轉視角但不能移動和開火。回合殲滅之後的每回合有 3 秒準備時間。被擊倒的人會往被打的方向倒下：死鬥模式躺一下就消失，回合殲滅留到這回合結束。

## 裝備套裝
- 主頁「裝備」裡有三個套裝欄位，每一欄自己挑：主武器、副武器、刀、投擲物 ×2（投擲物是爆破模式限定，現在的模式還不能用）
- 主武器：
  - 突擊步槍：全自動，什麼距離都能打（25 / 爆頭 70）
  - 衝鋒槍：射速最快、跑得快（108%），遠距離傷害會掉（20 → 14）
  - 泵動霰彈槍：一發 8 顆彈丸，近距離一發擊倒；每發要泵動；一顆一顆裝彈，裝到一半可以直接開槍
  - 栓動狙擊槍：5 發，開鏡打胸口以上一發擊倒（腹部、腿兩發）；每發都要拉栓（會自動退出狙擊鏡，拉完再自動開鏡）
  - 半自動狙擊槍：7 發，可以連發；身體兩發、爆頭一發擊倒
- 副武器：手槍（22 / 65，12 發）、大口徑手槍（身體三發、爆頭一發，7 發，後座大）
- 刀：戰術刀（55，背刺 100，移動 110%）
- 距離衰減：每把槍超過有效距離傷害會變小（狙擊槍不衰減），裝備畫面會顯示有效距離
- 瞄準：電腦按右鍵（拿刀時是重擊），手機按 ◎；每把槍放大倍率、開鏡速度不一樣，瞄準時比較準、走比較慢，跳起來不能瞄
  - 設定 →「瞄準」可以選「點一下切換」或「按住瞄準」（手機預設點一下、電腦預設按住），也可以調開鏡靈敏度
  - 兩把狙擊槍開好鏡才準；不開鏡沒有準心，子彈落在以畫面中心為圓心的大圈圈裡；狙擊鏡會微微晃
  - 伺服器會檢查有沒有真的開好鏡；霰彈槍彈丸和盲狙的落點用同一個亂數種子，你看到的跟伺服器算的一樣
- 對戰中「死掉等重生」「開場準備時間」「剛復活 10 秒內、還沒開火、還沒走出重生區（走回去也不行）」可以換套裝（電腦按 B，手機點畫面上方的「換套裝」）
- 切換武器：電腦按 1 / 2 / 3 或滾輪；手機點「⇄」在兩把武器之間切換，按住會跳出另外兩把，滑過去放開就換成那把，之後點一下就在這兩把之間切換
- 武器有細緻的方塊風模型和第一人稱的手（袖子是隊伍色）：開槍時槍機／套筒會動、彈殼噴出來；手槍打光時套筒停在後面；子彈打光才換彈會比較久（步槍 2.3 秒、手槍 1.6 秒，要多拉槍機／放套筒）
- 刀：輕擊照順序輪流三種揮法（斜砍 → 反手橫揮 → 直刺）；重擊電腦按右鍵、手機按住開槍鈕舉刀，放開砍下（傷害 80）
- 檢視武器：電腦按 F，手機點右下角的彈藥數字；每把武器的檢視動作都不一樣
- 回合殲滅觀戰時，畫面上會顯示被觀戰的人手上的武器、血量和子彈，開槍、換彈、揮刀都會同步
- 對戰結束時先播「🏆 最佳擊殺」：整場最精彩的一次擊殺（爆頭、遠距離、連殺、刀殺、盲狙、殘血反殺加分），用擊殺者的視角重播前後幾秒，擊殺瞬間放慢；可以按「跳過」
- 被擊倒時會顯示對方用什麼武器、還剩幾滴血
- 準心是半透明細線：站著不動時最小，走路、跳躍、連射時會張開，代表子彈的散布（邊走邊開槍比較不準，機器人也一樣）
- 每把武器的槍聲、換彈聲都不一樣（全部用程式合成），別人換彈時看得到也聽得到
- 機器人也用同一套規則：開場依難度隨機挑套裝（新手比較少拿狙擊槍）；主武器打完會切手槍（新手只會原地換彈），敵人貼很近時可能拔刀；狙擊手會先開鏡、瞄一下才開槍，被貼臉會拔手槍；拿霰彈槍的會往前壓
- 武器數值在 `public/weapons.js`，伺服器和瀏覽器共用

## 爆破模式
- 房主在等待室選「爆破」；地圖固定是**霓虹地鐵站**；回合數可以選先贏 5／7／9，打完上半場（先贏 N → 前 N-1 回合）兩隊交換攻守
- 每回合：準備 10 秒（可以換套裝）→ 1 分 45 秒；死了等下一回合（觀戰）
- 進攻方隨機一人拿炸彈（隊友頭上看得到 💣）；在 A 或 B 包點按住 **E**（手機「💣 埋彈」）3 秒埋彈，不能動、開槍會中斷
- 炸彈埋下後倒數 40 秒；防守方靠近按住 **E**（手機「✂ 拆彈」）6 秒拆除；爆炸範圍 18 公尺，誰都會被炸
- 勝利方式：防守方全滅／炸彈爆炸 → 進攻方贏；進攻方全滅（還沒埋）／時間到／拆除炸彈 → 防守方贏
- 拿炸彈的人死掉，炸彈會掉在地上，進攻方走過去就撿起來

## 投擲物（爆破模式限定）
套裝的兩個投擲物欄位可以選這 5 種（同一種可以選兩次），每回合各一顆：
- 💣 **手榴彈**：1.6 秒後爆炸，6.5 公尺內最多 100 傷害（被牆擋住就沒事）；會炸到自己，不會炸到隊友；可以暫時炸開煙霧
- ✨ **閃光彈**：1.4 秒後爆開，看著它的人白畫面約 3 秒（側面 1.5 秒、背對 0.4 秒）；自己也會被閃
- 💨 **煙霧彈**：停下來後冒出半徑 4.5 公尺的濃煙 15 秒；機器人也看不穿；會蓋掉火焰
- 🔥 **火焰彈**：碰到地面就燒起來，半徑 3 公尺、7 秒、每秒約 32 傷害；**隊友和自己也會被燒**；丟進煙裡會熄掉
- 🚨 **震撼彈**：1.4 秒後爆開，8 公尺內看得到它的人約 3 秒畫面搖晃、移動和轉身變慢
- 電腦：按 **4** 切到投擲物（再按一次換另一顆），按住左鍵出現拋物線、放開丟遠；右鍵是丟近
- 手機：從 ⇄ 選單選投擲物，按住開槍鈕出現拋物線、放開丟出去；◎ 切換丟遠／丟近

## 地圖
房主在等待室選地圖：
- **霓虹碼頭**（80 × 80，預設）：三條路線的戰術地圖
  - A 倉庫：有屋頂的室內走廊，轉角多，適合近戰；北邊有後巷可以繞路
  - B 廣場：中央高台（兩側樓梯、前後可以跳上去）搶控制，塔擋住兩邊出生點的視線
  - C 碼頭：貨櫃、瞭望台和高架步道，視野長，適合遠距離
- **經典競技場**（50 × 50）：原本的小地圖，節奏快
- **霓虹地鐵站**（110 × 90，爆破模式用）：北邊防守方、南邊進攻方；A 包點是室內站廳（有二樓夾層），B 包點是露天貨場（可以爬貨櫃）；進攻方有 A 大道、A 小巷、中路、B 地道、B 大門五條路

## 機器人
- 房主在等待室按各隊的「＋ 機器人」加入，可選 **新手／普通／老手**；或按「自動補滿兩隊」一次補滿
- 機器人算在每隊 5 人的名額裡，房主可以按 ✕ 移除
- 機器人跟真人同一套規則（血量、射速、彈匣、命中判定），看不到牆後面的人，但聽得到附近的槍聲
- 會用 A* 尋路繞過障礙物；交戰時會瞄準、連射、走位，血少時找掩護
- 視線檢查胸口、頭、左右肩膀和腳，敵人露出一部分就看得到；敵人躲進掩體 0.8 秒內還會瞄著最後看到的位置（不會一直開關鏡、重新反應）
- 一直打不中（對方躲在矮牆後只露一點）時會瞄露出來的部位，或換到看得比較清楚的位置
- 拿霰彈槍的：太遠先拔手槍邊打邊用尋路繞過去，進到 11 公尺內換回霰彈槍
- 會走樓梯、跳上箱子和貨櫃、從高處跳下來，也會去搶高台和掩體守點（老手最常這樣做）
- 難度參數在 `bots.js` 最上面的 `LEVELS`，可以直接調整

## 設定
- **基本**：視野、音效／音樂音量、畫質
- **瞄準**：滑鼠／觸控靈敏度、垂直靈敏度、反轉上下、瞄準輔助（關／弱／強；手機預設弱、電腦預設關。準心在敵人身上時轉動稍慢，開槍時輕輕帶向敵人，往反方向轉時不干擾）
- **按鍵**：電腦可以重新綁定每個動作的按鍵（含滑鼠按鍵）；手機可以調整按鈕大小、拖曳按鈕位置

## 手機玩建議
- 標題畫面右上角有「⛶ 全螢幕」按鈕，先在選單按下去，進入對戰後就不會再跳全螢幕提示
- 更好的方式：用 Chrome 打開網址 → 右上角 ⋮ →「加到主畫面」（或「安裝應用程式」），之後從桌面圖示打開就是全螢幕、橫向，也沒有網址列

## 本機執行
```bash
npm install
npm start
```
打開 http://localhost:3000 。同一個 Wi-Fi 的朋友可以用 `http://你的電腦IP:3000` 加入。

## 部署上網（Render 免費方案）
1. 到 https://render.com 用 GitHub 帳號登入
2. New → Blueprint，選這個 repo（會讀取 `render.yaml` 自動設定）
3. 等它建置完成，會拿到一個 `https://xxxx.onrender.com` 網址，傳給朋友就能一起玩

> 免費方案閒置 15 分鐘會休眠，第一個人打開時要等約 30 秒～1 分鐘喚醒。

也可以部署到任何支援 Node.js 18+ 和 WebSocket 的平台（Railway、Fly.io 等），啟動指令是 `npm start`，伺服器會讀取 `PORT` 環境變數。

## 檔案結構
- `server.js`：伺服器（大廳、房間、對戰流程、位置同步、命中判定含延遲補償）
- `bots.js`：機器人（尋路、視線、瞄準、行為、難度設定）
- `geom.js`：射線判定等幾何計算
- `public/map.js`：地圖資料（伺服器和瀏覽器共用）
- `public/world.js`：地圖外觀（材質、燈光、天空、裝飾）
- `public/weapons.js`：武器數值與套裝規則（伺服器和瀏覽器共用）
- `public/loadout.js`：裝備畫面
- `public/viewmodel.js`：第一人稱武器模型與動畫
- `public/game.js`：遊戲畫面、操作、物理、音效（Three.js）
- `public/index.html`、`public/style.css`：介面
